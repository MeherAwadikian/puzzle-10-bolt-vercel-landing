# Puzzle #10 — Landing Page Deployed to Vercel via GitHub

Original puzzle brief: "deploy a Bolt landing page to Vercel. Built in Bolt, .bolt folder
removed, pushed to GitHub, GitHub connected to Vercel, deployed on Vercel."

## Substitution note

No Bolt.new account exists on this machine (same situation as puzzle #5). The real,
testable deliverable here is the pipeline: a real landing page, in a real GitHub repo,
connected to and deployed on Vercel. The page itself was built directly as static
HTML/CSS instead of through Bolt's generator. Everything downstream (git, GitHub, Vercel
project link, live deploy) is real and unmodified from what the puzzle asks for.

## Stack

Plain static HTML + CSS, no build step, no framework. Deployed to Vercel as a static site.
